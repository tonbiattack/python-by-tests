# Python by Tests

**Python by Tests** は、Python の言語仕様・標準ライブラリ・実行時の挙動を、短い Source と Test から理解するための実行可能ドキュメント教材です。

一般的な Python 入門や文法リファレンスを目指すのではなく、**コードを実際に動かしてテストすることで理解が一段深くなる挙動**を扱います。

主な対象は次の3種類です。

- **Pitfall**: 間違えやすい、直感と結果がずれやすい挙動
- **Behavior**: 言語仕様や標準ライブラリの重要な実行時挙動
- **Concept**: Python の重要概念をテスト結果から理解できる題材

教材追加・実装時の詳細な方針は [`docs/EXPANSION_GUIDE.md`](./docs/EXPANSION_GUIDE.md) を参照してください。

公開サイト: [tonbiattack.github.io/python-by-tests](https://tonbiattack.github.io/python-by-tests/)
